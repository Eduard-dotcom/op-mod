**ИТОГО: 111 уникальных ошибок** в 10 уровнях серьёзности.

### Ключевые выводы из сравнения 4 источников:

1. **Ошибки WrapObject (#27-45)** — основная причина ошибки `PropertyObjArray: ERR- Attempting to append invalid object`. Самые критичные: отсутствие radius/length у WrapCylinder, отсутствие quadrant, VisibleObject в формате OS 4.x.

2. **Дубликаты имён (#13-19)** — вторая по частоте причина. Особенно дубликаты PathPoint (#19).

3. **Ссылочная целостность (#46-57)** — краш при initSystem(). Висячие ссылки на body, coordinate, wrap_object.

4. **Численная стабильность (#73-97)** — NaN при симуляции. Критично: микроскопическая масса, экстремально малый tendon_slack_length, невалидный тензор инерции.

5. **Формат VisibleObject (#43)** — специфическая ошибка для моделей, перенесённых из OpenSim 4.x в 3.3.
