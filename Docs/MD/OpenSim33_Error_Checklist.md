# ПОЛНЫЙ ПЕРЕЧЕНЬ ОШИБОК OpenSim 3.3 — ПРИ КОТОРЫХ МОДЕЛЬ НЕ ЗАГРУЖАЕТСЯ

На основе документации OpenSim 3.3 API (doc.7z) и исходного кода.

---

## РАЗДЕЛ 1: ОШИБКИ XML ДЕСЕРИАЛИЗАЦИИ (фаза чтения файла)

### 1.1 Структура XML документа
| # | Ошибка | Описание |
|---|--------|----------|
| 1 | Неверный XML заголовок | Отсутствует `<?xml version="1.0" encoding="UTF-8"?>` или некорректный |
| 2 | Отсутствует `<OpenSimDocument>` | Корневой тег должен быть `<OpenSimDocument Version="30000">` |
| 3 | Неверная версия документа | `Version` должна быть `"30000"` для OpenSim 3.3 |
| 4 | Отсутствует `<Model>` | Должен быть дочерним элементом `<OpenSimDocument>` |
| 5 | Незакрытый тег | Любой незакрытый XML тег вызывает ошибку парсинга |
| 6 | Нарушена иерархия вложенности | Теги должны быть правильно вложены (Body внутри BodySet и т.д.) |
| 7 | Некорректные символы | Символы вне UTF-8 или спецсимволы без экранирования |

### 1.2 Регистрация типов объектов
| # | Ошибка | Описание |
|---|--------|----------|
| 8 | Незарегистрированный тип XML-тега | Каждый тег (WrapCylinder, Thelen2003Muscle и т.д.) должен быть зарегистрирован через `Object::registerType()` |
| 9 | `concreteClassName` не найден | Если атрибут типа не соответствует ни одному зарегистрированному классу |
| 10 | Несовместимый тип в PropertyObjArray | Объект в Set должен быть производным от базового типа Set (напр. WrapCylinder в WrapObjectSet — OK, другой тип — ОШИБКА) |

### 1.3 Свойства объектов (Property System)
| # | Ошибка | Описание |
|---|--------|----------|
| 11 | Отсутствует обязательное свойство | Свойства, объявленные как обязательные, должны присутствовать в XML |
| 12 | Неверный тип значения | Текст где ожидается число, или наоборот |
| 13 | Неправильный порядок свойств | Свойства должны идти в порядке объявления в классе |
| 14 | Неизвестное имя свойства | Тег, не соответствующий ни одному объявленному свойству объекта |
| 15 | Пустое значение числового свойства | `<radius></radius>` или `<radius> </radius>` для числового поля |

## РАЗДЕЛ 2: ОШИБКИ ОБЪЕКТОВ Body (тела)

| # | Ошибка | Описание |
|---|--------|----------|
| 16 | Отсутствует `name` у Body | Каждый Body должен иметь уникальное имя |
| 17 | Дублирующееся имя Body | Два Body с одинаковым именем в BodySet |
| 18 | Отрицательная масса | `mass < 0` недопустимо (0 — допустимо для ground-подобных тел) |
| 19 | Отсутствует `mass_center` | Должен быть Vec3 (x y z) |
| 20 | Отсутствуют компоненты инерции | Должны быть: `inertia_xx`, `inertia_yy`, `inertia_zz` (как минимум; `inertia_xy`, `inertia_xz`, `inertia_yz` — могут быть 0) |
| 21 | Невалидная матрица инерции | Не является положительно полуопределённой |
| 22 | Отсутствует `VisibleObject` | Body должен содержать VisibleObject (даже пустой) |
| 23 | Отсутствует `WrapObjectSet` | Body должен содержать WrapObjectSet (даже пустой: `<objects />` + `<groups />`) |
| 24 | Отсутствует `Joint` внутри Body | Каждый Body (кроме ground) должен иметь Joint |

## РАЗДЕЛ 3: ОШИБКИ ОБЪЕКТОВ Joint (суставы)

| # | Ошибка | Описание |
|---|--------|----------|
| 25 | `parent_body` не найден | Имя родительского тела не соответствует ни одному Body в BodySet |
| 26 | Parent body не подключён | Родительское тело не имеет MobilizedBodyIndex (не связано в графе) |
| 27 | Неверный тип сустава | Незарегистрированный тип (должен быть: PinJoint, BallJoint, UniversalJoint, CustomJoint, WeldJoint, SliderJoint, FreeJoint и т.д.) |
| 28 | CustomJoint без SpatialTransform | CustomJoint требует 6 TransformAxis внутри `<SpatialTransform>` |
| 29 | SpatialTransform с невалидной Function | TransformAxis ссылается на несуществующую или некорректную функцию |
| 30 | Отсутствуют `location_in_parent` / `location` | Должны быть Vec3 |
| 31 | Отсутствуют `orientation_in_parent` / `orientation` | Должны быть Vec3 |
| 32 | Нарушена последовательность связности | Тела должны быть связаны в дерево от ground; циклы запрещены без Constraint |
| 33 | Ground не найден | Body `"ground"` должен существовать в модели |

## РАЗДЕЛ 4: ОШИБКИ ОБЪЕКТОВ Coordinate (координаты)

| # | Ошибка | Описание |
|---|--------|----------|
| 34 | `motion_type` невалиден | Должен быть: `"rotational"`, `"translational"` или `"coupled"` |
| 35 | `range` min > max | Минимальное значение диапазона больше максимального |
| 36 | `prescribed=true` без функции | Если prescribed=true, должно быть указано `prescribed_function` |
| 37 | Отсутствует `default_value` | Числовое значение по умолчанию |
| 38 | Дублирующееся имя координаты | Два Coordinate с одинаковым именем |
| 39 | Координата не привязана к суставу | Coordinate внутри Joint, но Joint не существует |

## РАЗДЕЛ 5: ОШИБКИ ОБЪЕКТОВ WrapObject (WrapCylinder, WrapEllipsoid, WrapSphere)

| # | Ошибка | Описание |
|---|--------|----------|
| 40 | Незарегистрированный тип WrapObject | Тип тега не является WrapCylinder/WrapEllipsoid/WrapSphere |
| 41 | Отсутствует `name` | Каждый WrapObject должен иметь уникальное имя внутри Body |
| 42 | Дублирующееся имя WrapObject в одном Body | Два wrap-объекта с одинаковым именем в одном Body |
| 43 | Отсутствует `active` | Должно быть `true` или `false` |
| 44 | Неверное значение `active` | Не `true`/`false` (напр. с пробелами: ` true `) |
| 45 | Отсутствует `quadrant` | Должен быть: `x`, `y`, `z`, `-x`, `-y`, `-z`, `all` |
| 46 | Неверное значение `quadrant` | Заглавная буква (`Y` вместо `y`), пробелы, неизвестное значение |
| 47 | Отсутствует `translation` | Должен быть Vec3 (x y z) |
| 48 | Отсутствует `xyz_body_rotation` | Должен быть Vec3 (rx ry rz в радианах) |
| 49 | Отсутствует `display_preference` | Должен быть 0-4 (0=Hide, 1=Wire, 3=Flat, 4=Shaded) |
| 50 | Несовместимый VisibleObject внутри WrapObject | VisibleObject в формате OpenSim 4.x (с `<geometry_files>`, `<VisibleProperties>`, `<material_name>`) — **ОШИБКА для OpenSim 3.3** |
| 51 | WrapCylinder: отсутствует `radius` | Числовое положительное значение |
| 52 | WrapCylinder: `radius <= 0` | Радиус должен быть положительным |
| 53 | WrapCylinder: отсутствует `length` | Числовое положительное значение |
| 54 | WrapCylinder: `length <= 0` | Длина должна быть положительной |
| 55 | WrapEllipsoid: отсутствует `dimensions` | Должен быть Vec3 (dimX dimY dimZ) |
| 56 | WrapEllipsoid: `dimensions` с неположительными значениями | Все три размерности должны быть > 0 |
| 57 | WrapSphere: отсутствует `radius` | Числовое положительное значение |
| 58 | WrapSphere: `radius <= 0` | Радиус должен быть положительным |
| 59 | WrapObject вне Body | WrapObject должен находиться внутри `<WrapObjectSet>` внутри `<Body>` |

## РАЗДЕЛ 6: ОШИБКИ ОБЪЕКТОВ Muscle / Force (мышцы и силы)

| # | Ошибка | Описание |
|---|--------|----------|
| 60 | Незарегистрированный тип мышцы/силы | Thelen2003Muscle, Millard2012EquilibriumMuscle, Schutte1993Muscle и т.д. — должны быть зарегистрированы |
| 61 | `max_isometric_force <= 0` | Должно быть положительным |
| 62 | `optimal_fiber_length <= 0` | Должно быть положительным |
| 63 | `tendon_slack_length < 0` | Должно быть неотрицательным |
| 64 | `pennation_angle_at_optimal` невалиден | Должен быть в радианах, >= 0 |
| 65 | `max_contraction_velocity <= 0` | Должно быть положительным |
| 66 | `min_control > max_control` | min должен быть <= max |
| 67 | Отсутствует `GeometryPath` | Мышца должна иметь GeometryPath |
| 68 | PathPointSet пустой | Минимум 2 PathPoint для определения пути мышцы |
| 69 | PathPoint ссылается на несуществующий Body | Свойство `body` у PathPoint должно совпадать с именем Body |
| 70 | PathWrap ссылается на несуществующий WrapObject | `name` или `wrap_object` должен совпадать с именем WrapObject в указанном Body |
| 71 | PathWrap: `method` невалиден | Должен быть: `hybrid`, `midpoint`, или `axial` |
| 72 | Отсутствует `isDisabled` у Force | Должно быть `true` или `false` |
| 73 | Дублирующееся имя мышцы/силы в ForceSet | Два объекта с одинаковым именем |
