ФАЗА 1: ОШИБКИ ВВОДА-ВЫВОДА И XML-СИНТАКСИСА (Файл не откроется вообще)
████████████████████████████████████████████████████████████████████████████████
На этом этапе срабатывает стандартный XML-парсер. OpenSim даже не начинает читать биомеханику.

[  ] 1.1.  Файл .osim не найден, усечён (обрывается посередине) или нет прав на чтение.
[  ] 1.2.  Неверный или отсутствующий XML-заголовок: <?xml version="1.0" encoding="UTF-8"?>
[  ] 1.3.  Отсутствует корневой тег <OpenSimDocument> или неверный атрибут Version
           (для OpenSim 3.3 должно быть Version="30000").
[  ] 1.4.  Отсутствует дочерний тег <Model> внутри <OpenSimDocument>.
[  ] 1.5.  Незакрытые или неправильно вложенные теги
           (например: <Body>...<Joint>...</Body> — забыт </Joint>).
           Реакция: XML Parse Error: mismatched tag.
[  ] 1.6.  Недопустимые символы без экранирования: &, <, > внутри значений тегов.
           Правильно: &amp; &lt; &gt;
[  ] 1.7.  Файл сохранён в кодировке, отличной от UTF-8.
[  ] 1.8.  Дубликаты атрибутов в одном теге (name="x" name="x").
           Реакция: XML Parse Error: attribute redefined.
[  ] 1.9.  Незакрытая кавычка в атрибуте (name="femur>).
[  ] 1.10. Пропущена закрывающая скобка > в теге (<Body name="femur").
[  ] 1.11. Теги записаны в разном регистре (body вместо Body).
           OpenSim требует точного совпадения имён классов.
[  ] 1.12. Нарушена иерархия вложенности (тело вне BodySet, мышца вне ForceSet).
[  ] 1.13. Недопустимые символы в атрибуте name объекта (пробелы, спецсимволы).
[  ] 1.14. Пустые значения числовых свойств (<radius></radius> или <radius> </radius>).


████████████████████████████████████████████████████████████████████████████████
ФАЗА 2: ДЕСЕРИАЛИЗАЦИЯ И СТРУКТУРА ОБЪЕКТОВ (Краш парсера OpenSim)
████████████████████████████████████████████████████████████████████████████████
XML синтаксически верен, но нарушены строгие правила объектной модели OpenSim (SimTK).

[  ] 2.1.  Незарегистрированный тип XML-тега — каждый тег должен быть зарегистрирован
           через Object::registerType(). Если тег не распознан — объект не создаётся.
[  ] 2.2.  concreteClassName не найден — атрибут типа не соответствует ни одному
           зарегистрированному классу. newInstanceOfType() возвращает NULL.
[  ] 2.3.  Несовместимый тип в PropertyObjArray — объект в Set не является производным
           от базового типа Set (напр. WrapCylinder в WrapObjectSet — OK, другой тип — ОШИБКА).
           Реакция: PropertyObjArray: ERR- Attempting to append invalid object of type...
[  ] 2.4.  Отсутствует обязательное свойство — свойства, объявленные как обязательные,
           должны присутствовать в XML. Без них объект считается «invalid».
[  ] 2.5.  Неверный тип значения свойства — текст где ожидается число,
           "yes" вместо "true"/"false". Реакция: InvalidValue.
[  ] 2.6.  Неправильный порядок свойств XML — свойства должны идти в порядке
           объявления в классе. Нарушение порядка может привести к молчаливой
           ошибке или неправильному присвоению.
[  ] 2.7.  Неизвестное имя свойства — тег не соответствует ни одному объявленному
           свойству класса.
[  ] 2.8.  Невалидные значения перечислений (Enums) —
           motion_type="linear" вместо "translational"/"rotational".
[  ] 2.9.  В любом Set ОБЯЗАТЕЛЬНО должны присутствовать теги <objects> и <groups>
           (даже пустые: <groups />). Отсутствие — ошибка структуры.
