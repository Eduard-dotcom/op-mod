====================================================
  Z.ai Chat Client — Установка для Windows 7
====================================================

ВАЖНО: Этот Python 3.8 ПОРТАТИВНЫЙ — он НЕ конфликтует
с Python 2.7 от OpenSim! Никаких изменений в реестр
и PATH не вносится.

====================================================
  УСТАНОВКА (один раз)
====================================================

1. Скачай Python 3.8.10 embeddable:
   https://www.python.org/ftp/python/3.8.10/python-3.8.10-embed-amd64.zip
   (Размер ~7 МБ)

2. Распакуй содержимое ZIP-архива в папку:
   zai_chat_win7\python\
   
   Чтобы файл python.exe лежал по пути:
   zai_chat_win7\python\python.exe

3. Запусти: двойной клик на START_CHAT.bat

4. Откроется браузер с адресом http://localhost:8080

====================================================
  КАК ПОЛУЧИТЬ ТОКЕН
====================================================

Ты зарегистрирован через GitHub, поэтому:

СПОСОБ 1 (с телефона — проще всего):
  1. Открой chat.z.ai на телефоне
  2. Войди через GitHub
  3. Нажми на адресную строку и набери:
     javascript:document.title=localStorage.token
  4. Токен появится в заголовке вкладки — скопируй
  5. Перешли себе (Telegram, почта, записка)

СПОСОБ 2 (с компьютера):
  1. Открой chat.z.ai в Firefox (если установлен)
     Firefox на Win7 обновляется дольше Chrome
  2. Войди через GitHub
  3. Нажми F12 → Консоль → набери:
     copy(localStorage.token)
  4. Токен скопирован в буфер обмена

СПОСОБ 3 (совсем хитрый):
  1. Открой chat.z.ai в ЛЮБОМ браузере
  2. Войди через GitHub
  3. Нажми Ctrl+Shift+Delete → Удалить всё КРОМЕ куки
  4. В адресной строке набери:
     javascript:void(document.title=localStorage.token)
  5. Токен в заголовке вкладки

====================================================
  ЧАСТЫЕ ВОПРОСЫ
====================================================

Q: Конфликтует ли с Python 2.7 от OpenSim?
A: НЕТ! Это портативная версия (embed). Она лежит
   в своей папке и не меняет PATH или реестр.
   OpenSim продолжит использовать свой Python 2.7.

Q: Какой браузер использовать?
A: Любой! Internet Explorer, старый Chrome, Firefox.
   Клиент работает даже в IE8.

Q: Токен истёк / не работает?
A: Получи новый тем же способом. Токены живут долго,
   но иногда нужно обновить.

Q: Не открывается страница?
A: Проверь что скрипт запущен (окно командной строки
   открыто). Открой http://localhost:8080 вручную.
